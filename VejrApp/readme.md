## Redigér hjemmesiden

Siderne er Quarto-filer i mappen `site/`. Se ændringerne lokalt med:

```text
quarto preview site
```

Hjemmesiden bliver bygget og udgivet automatisk, når ændringer i `site/` bliver pushet til `main`.
